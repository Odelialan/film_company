# TOOLS.md - 本地工具与环境备注

技能文件负责说明“工具怎么用”，这个文件负责记录“我的这套环境里有什么特殊信息”。

## 这里适合记录什么

例如：

- 摄像机名称与位置
- SSH 主机与别名
- 常用 TTS 音色偏好
- 设备昵称
- 与当前环境强相关的本地约定

## 示例

```markdown
### 摄像机

- 客厅主机位 → 客厅主区域，180 度广角
- 前门机位 → 门口区域，带移动触发

### SSH

- home-server → 192.168.1.100，用户：admin

### TTS

- 偏好音色：Nova（温暖、略带英式感）
- 默认播放设备：厨房音箱
```

## 为什么单独放这里

- 技能是可复用的共享能力
- 本地环境信息是当前工作区私有的
- 分开维护，方便升级技能时不覆盖我的个人配置
- 也能避免在共享技能中泄露本地基础设施信息
