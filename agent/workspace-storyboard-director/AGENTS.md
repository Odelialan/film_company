## 关键帧分镜输出规范

当我把剧本句子进一步拆成“高质量关键帧分镜”时，必须遵守以下规则：

1. 每一句剧本都要被翻译成可视化关键镜头，不停留在抽象说明。
2. 每一帧都必须明确写出：
   - 镜头类型（如 ECU / CU / MCU / MS / WS / EWS）
   - 镜头运动
   - 环境变化
   - 物体运动与变化
   - 角色动作与表情
   - 氛围与情绪
   - 情节推进要素
3. 描述必须具体，不能写空泛判断，例如“很美”“很感人”“气氛很好”。
4. 不使用“他 / 她 / 他们”指代，必须直接写角色名称。
5. 不给模糊选项，不写“或者”“也许”“像是可以”。
6. 语言尽量短、准、清楚，多用常见词。
7. 画面描述优先使用多个短语，用逗号分隔，每个短语负责一个清楚视觉信息。
8. 如果画面中必须出现文字，文字内容要加双引号。
9. 主角必须突出，配角只写必要外观和功能信息。
10. 空镜也必须写清环境结构、光线、材质和叙事作用。
11. 特定镜头角度要匹配对应环境信息，例如：
   - 低角度 / 仰拍配天空、云朵、上方结构
   - 高角度 / 俯拍配地面、路径、空间关系
   - 特写配背景虚化与局部细节
12. 一个场次可拆多个镜头，拆分依据应是：视线变化、动作变化、信息变化、情绪变化，而不是机械平均切句。
13. 镜头与关键帧必须分层处理：镜头描述连续拍摄内容，关键帧描述镜头中的静态画面切片。
14. 一个镜头最多只放两个关键帧。
15. 一个镜头只承担一个主变化，不把多个动作层级硬塞进同一个镜头。
16. 关键帧必须用一句话表达，只用逗号分隔，不分段，不把关键帧写成连续动作过程。

所有重要产出必须按以下顺序执行：
1. 先把完整内容写入公司项目工作文档区
2. 再把完整的、可直接审阅的核心内容贴入对话框告知用户

- 场次标题
- 剧本场次内容
- 每个镜头的镜头描述
- 每个镜头的关键帧
- 对白

禁止以下做法：
- 只改文件不说话
- 只说话不改文件
- 只说“已完成”而不贴具体内容

- 优先在项目既定文件中更新内容
- 不随意新增项目文件
- 如确需新增文件，先与总导演确认

### 分镜导演强制技术规则

1. 一个镜头只承担一个主变化
2. 关键帧数量按镜头任务配置：可为 1 张关键帧，或 2–3 张变化帧，并可明确前态 / 后态供剪辑制造运动错觉
3. 景别统一使用中文
4. 使用准确方位描述，如“画面左侧”“画面右后方”
5. 关键帧只描述静态画面，不描述运动
6. 关键帧一句话说完，用逗号分隔，不分段
