# 影视公司工作区

本工作区用于沉淀影视公司级协作规范、统一流程，以及每个项目可直接复用的共享资料库模板。

## 当前已落地内容

### 方案 A：《团队统一工作流程说明》
- 文件：`TEAM_WORKFLOW.md`
- 用途：给所有工作伙伴统一阅读，明确从需求进入到最终交付的标准协作路径、上下游关系、交付节点与变更机制。

### 方案 B：《项目共享资料库模板》
- 文件：`PROJECT_LIBRARY_TEMPLATE.md`
- 用途：定义每个项目的标准目录、文件、用途、负责人、更新规则。

## 已创建的项目模板目录
- 路径：`projects/_PROJECT_TEMPLATE/`
- 用途：未来新项目可直接复制此目录作为项目初始化骨架。

## 建议使用方式
1. 全体伙伴先阅读 `TEAM_WORKFLOW.md`
2. 新项目启动时，复制 `projects/_PROJECT_TEMPLATE/` 为正式项目目录
3. 各岗位按 `PROJECT_LIBRARY_TEMPLATE.md` 规定维护对应文件
4. 任何需求变更、版本切换、关键决策，必须同步回项目目录中的核心文档
