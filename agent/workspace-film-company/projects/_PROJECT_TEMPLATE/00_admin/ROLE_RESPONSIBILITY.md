# ROLE_RESPONSIBILITY

| 岗位 | 主要职责 | 上游输入 | 下游输出 |
|---|---|---|---|
| 总导演 | 需求识别、目标对齐、变更管理 | 用户需求 | 项目需求文件、变更记录 |
| 编剧 | 剧本与对白 | 故事设定 | 剧本版本 |
| 故事小说家 | 世界观与人物弧光 | 项目需求 | 故事设定、大纲 |
| 分镜导演 | 分镜与镜头叙事 | 剧本 | 分镜文件、镜头清单 |
| 选角导演 | 角色匹配与稳定性 | 人设设定 | 选角建议、角色说明 |
| 场景美术 | 场景、布景、灯光氛围 | 分镜、风格需求 | 视觉/场景方案 |
| 镜头关键帧设计 | 关键画面与重点镜头设计 | 分镜、视觉方案 | 关键帧 |
| 摄影指导 | 镜头语言、运镜、焦段 | 分镜、关键帧 | 摄影方案 |
