## 文件结构标准

```
07_keyframes/
├── KEYFRAME_FILE_STRUCTURE.md   # 本文件，目录说明与文件结构规范
├── KEYFRAME_PLAN.md             # 关键帧计划、索引表、优先级
├── SEEDREAM_KEYFRAMES.md        # 【主文件】Seedream 工具关键帧提示词（分支1：有参考图）
└── KEYFRAMES/                   # 【图片文件夹】用于放置生成的关键帧图片
```

**重要说明**：
- `KEYFRAMES/` 文件夹保留，用于后续放置 Seedream 工具生成的关键帧图片
- 图片命名规则：`KF{场次}-{镜头}-{关键帧编号}.png`（例：`KF1-1-1.png`，`KF1-1-2.png`）

## 各文件说明

### 1. KEYFRAME_PLAN.md
- **用途**：关键帧计划、索引表、固定参考图清单、交付进度跟踪
- **维护人**：镜头关键帧设计
- **包含内容**：
  - 强制风格统一要求
  - 设计原则与上游依赖
  - 固定参考图全局编号表（G1、G2…）
  - 各场次关键帧交付清单（带勾选框）
  - 进度跟踪表

### 2. SEEDREAM_KEYFRAMES.md（唯一主文件）
- **用途**：Seedream 工具可直接调用的完整提示词（分支1：有参考图）
- **标准**：严格按《关键帧设计岗位标准》执行
- **格式要求**：
  - 每个镜头包含：镜头描述 + 运镜提示词 + 关键帧提示词 + 传入参考图
  - 提示词结构：景别 + 镜头角度 + 构图 + 角色(参考图编号) + 地点环境 + 光影 + 色调 + 风格
  - 每个关键帧单独列出「传入参考图」清单，按顺序排列
  - **连续性简化原则**：连续镜头只参考前一帧，不重复参考原始角色图
- **维护人**：镜头关键帧设计

### 3. KEYFRAMES/（图片文件夹）
- **用途**：存放 Seedream 工具生成的关键帧图片
- **命名规则**：`KF{场次}-{镜头}-{编号}.png`
- **初始状态**：空文件夹，图片生成后逐步填入

## 提示词格式示例（正确格式，V3.0+）

```
## 场次 1｜【场次名称】

### 镜头 1-1（需要2个关键帧）
- **镜头描述**：【原分镜导演内容】
- **运镜提示词**：缓慢推镜，从教室门口慢慢推进到积木区，全景
- **关键帧 1**：【画面状态描述】
  - **提示词**：全景，平视角度，从教室门口构图，积木区在画面深处，【地点】，【光影】，【色调】，3D CGI 卡通风格，柔和圆润无尖锐棱角
  - **传入参考图**：G4（场景全景参考图）
- **关键帧 2**：【画面状态描述】
  - **提示词**：全景，平视角度，参考本镜头关键帧 1 构图，推镜结束，【地点】，【光影】，【色调】，3D CGI 卡通风格，柔和圆润无尖锐棱角
  - **传入参考图**：本镜头关键帧 1
```

**格式要点**：
- ✅ 镜头描述下方必须有独立的「运镜提示词」
- ✅ 每个关键帧有独立完整的提示词（按结构公式）
- ✅ 每个关键帧明确列出所有传入参考图，按顺序排列
- ❌ 不需要添加统一要素（分支1专用）
- ❌ 不需要完整的分支2提示词结构
