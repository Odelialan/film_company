## Polly 角色模板（固定不可改）
- 身份 / 年龄感：儿童向固定 IP 角色，年龄感偏幼态、陪伴型
- 外形关键词：圆润、3D 萌系玩偶感、黄色卷团发型、红色圆鼻头、黑色小眼睛、粉白脸、蓝色连帽卫衣、胸前红底黄字字母徽章、红色鞋子
- 性格关键词：亲和、鼓励式、轻松、温暖、适合儿童启蒙
- 核心欲望：帮助孩子在轻松情境里开口学英语、建立安全感和参与感
- 核心恐惧：不写成焦虑型或命令型老师感
- 行为习惯：鼓励、示范、邀请互动、用简单英语带动孩子回应
- 标志性动作：抬手示意、俯身鼓励、用短句带读、用笑眼和手势建立安全感
- **不可变动项**：黄色卷团发型、红鼻头、黑色小眼睛、蓝色卫衣、胸前字母徽章、红色鞋子、整体圆润萌系比例
- **可弹性调整项**：表情变化、手势动作、局部姿态

## 小朋友角色模板
- 身份 / 年龄感：4-6 岁儿童，幼儿园大班到学龄前阶段
- 性别感：中性偏男孩，降低受众排斥感
- 体型比例：头身比偏大，四肢短圆，玩偶化简化
- 外形关键词：圆脸、短鼻、小嘴、眼睛偏大、表情直接、脸颊微肉感
- 发型方向：深棕色或黑棕色短碎发，额前有自然刘海

- **可弹性调整项**：裤装细节、表情变化、手部道具（无字母无品牌）

## 三角色同框统一规则

### 1. 造型语言统一
- 三个角色统一采用圆润、明亮、亲和的 3D 萌系玩偶感
- 轮廓以圆、椭圆、软弧线为主，不使用尖锐棱角
- 面部结构尽量简化，保证多镜头生成时识别稳定

### 2. 视觉层级
- 第一识别锚点：Polly
- 第二识别锚点：访客/剧情角色的主色块 + 标志性动作
- 第三识别锚点：小朋友的主服装色彩与儿童比例

### 3. 配色分工
- Polly：蓝 + 黄 + 红，为固定核心配色
- 小朋友：暖黄 / 米黄 + 草绿点缀，作为温暖陪伴色
- 访客角色：与 Polly 的蓝卫衣 + 红鞋识别关系做明显区分

示例（P001）：
> 小恐龙：奶绿 + 浅米黄 + 草绿色背心，作为剧情情绪色

### 4. 多镜头一致性控制
- Polly 任何镜头都不能丢掉发型、红鼻头、蓝卫衣、红鞋四大识别锚点
- 小朋友任何镜头都要保持年龄感、短碎发、暖黄色主服装、圆脸比例
- 访客角色任何镜头都要保持主色块、核心服饰、特征部位（如尾巴/天线）
- 动作变化优先通过手势、头部角度、标志性部位来表现，不大改服装或结构

## 角色状态变化建议

### Polly
- 常规引导态：站立、俯身鼓励、抬手示意
- 互动带读态：单手指向目标，另一只手做鼓励动作
- 收尾陪伴态：站在活动区外方，微笑看着孩子和访客角色完成闭环

### 小朋友
- 初见态：微微仰头看 Polly 或访客角色
- 回应态：张嘴跟读、点头、挥手
- 玩耍态：与访客角色并排进行核心活动

- 初始态：
- 尝试态：
- 开心态：
