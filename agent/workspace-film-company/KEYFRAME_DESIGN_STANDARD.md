# 关键帧设计岗位标准（Seedream 工具提示词生产）

> 版本号：V4.0  
> 生效时间：2026-03-23  
> 维护人：总导演  
> 要求：关键帧设计岗位必须严格遵守此标准

---

## 一、核心目标

关键帧设计岗位的产出不是简单的画面描述，而是**可以直接被 Seedream 工具用于生产图片的完整提示词**。

---

## 二、两大分支判断

开始工作前，先明确项目类型：

| 分支 | 说明 | 本次 P002 项目 |
|---|---|---|
| **分支 1：有参考图的项目** | 有角色参考图、场景参考图 | ✅ 本次项目属于此分支 |
| **分支 2：无参考图的项目** | 无参考图，需自行生成完整描述 | ❌ 本次项目不属于此分支（但标准仍需保存） |

---

## 三、资产库体系

为了实现可复用的内容生产，建立以下资产库：

| 资产库 | 用途 | 存放内容 | 说明 |
|---|---|---|---|
| **角色库** | 固定 IP/角色 | Polly 等长期复用的角色 | 跨项目复用 |
| **项目角色库** | 单项目角色 | 本项目专用角色（如本项目的豆豆、Robby） | 选角导演生成，单项目使用 |
| **场景库** | 场景参考 | 各项目的场景生成图 | 场景美术调用 Seedream 生成 |
| **美术风格库** | 风格定义 | 皮克斯风格、迪士尼风格、手绘风格等 | 总导演与用户在阶段 1 确定 |
| **运镜模板库** | 镜头模板 | 常用运镜与镜头角度组合 | 可复用模板 |

### 3.1 全局参考图编号体系（V4.0 新增）

每个项目开始时，在 `KEYFRAME_PLAN.md` 和 `SEEDREAM_KEYFRAMES.md` 文件头部建立「固定参考图全局编号表」：

| 全局编号 | 命名规范 | 说明 |
|---|---|---|
| **G1** | 固定角色（跨项目复用，如 Polly） | 路径指向 `assets/characters/` |
| **G2** | 项目角色 A | 路径指向本项目 `02_characters/CHARACTER_REFERENCES/` |
| **G3** | 项目角色 B | 同上 |
| **G4** | 场景全景图 | 路径指向本项目 `06_scene/SCENE_REFERENCES/` |
| **GN+** | 按需增加 | 遵循相同规则 |

**全局编号仅用于索引**，提示词内实际使用「参考图 X」（指传入参考图的顺序编号），不直接写 G1/G2。

## 四、通用工作流程（两个分支都需遵守）

### 4.1 检查分镜与人物
1. 检查分镜内容，识别出场人物名称
2. 建立全局参考图编号表（G1、G2…），在 `KEYFRAME_PLAN.md` 和 `SEEDREAM_KEYFRAMES.md` 头部同步填写
3. 根据关键帧内容及出场人物，加入对应的角色描述
4. **有参考图时**：在提示词中明确说明「参考图 X」（X = 传入参考图顺序编号）
5. **无参考图时**：在每个镜头中有且只有一次加入每个角色描述

### 4.2 添加统一要素
根据画面是否包含人物或拟人化角色，添加对应的统一要素：

#### 4.2.1 包含人物或角色的画面要素
```
皮克斯风格，Q版，chibi风格，可爱、奇幻、色彩鲜艳，极致的线条和层次感，色彩鲜明且高对比的背景设计，创意十足，3D，UE5 虚幻引擎，写真级细节，多彩高质量图片，动画电影截图
```

#### 4.2.2 不包含人物或角色的纯场景空镜画面要素
```
无角色的场景插画，3D 极简建模，皮克斯风格，可爱、奇幻、色彩鲜艳，极致的线条和层次感，色彩鲜明且高对比的背景设计，创意十足，3D，UE5 虚幻引擎，写真级细节，多彩高质量图片，动画电影截图
```

### 4.3 角色一致性高度要求
- **有参考图时**：严格参考角色图片进行制作，并在提示词中明确说明参考哪张图片
- **无参考图时**：
  1. 画面风格由总导演和用户在阶段 1 确定
  2. 风格描述要完整、具体、可复用
  3. 示例（皮克斯风格）：见「4.2 统一要素」

## 五、分支 1：有参考图的分镜画面提示词构建方式

### 5.1 优化原则
1. **规避人物IP检测**：由名字改为「两个人」「一只小恐龙」等泛指
2. **动作描述更确定**：「进入」改为「走进」，避免不确定的动作词
3. **镜头运动参考图策略**：
   - 从无到有、镜头运动幅度大的镜头：两张首尾帧分别参考图片制作
   - 关键帧 2 由关键帧 1 运镜呈现：参考图为关键帧 1，而不是给场景或角色参考图
4. **连续性简化原则（V4.0 明确）**：连续镜头如果前一帧已包含所有角色/场景，当前帧只需参考前一帧，不需重复参考原始角色图

### 5.2 格式标准（重要，V4.0 更新）

**镜头描述部分**：
- 保留原分镜导演的内容
- 增加「运镜提示词」：专门描述运镜是如何进行的，明确运镜方式

**关键帧部分**：
- 保留原分镜导演的内容
- **每个关键帧必须单独构建完整提示词**，严格按照以下结构

**关键帧提示词结构公式（分支1 有参考图必须遵守）：**
```
提示词 = 景别 + 镜头角度 + 构图 + (角色A，参考图 X，简单的角色服装特征 + 动作 + 面向或者表情，位于画面的什么位置) + (角色B，参考图 X，简单的角色服装特征 + 动作 + 面向或者表情，位于画面的什么位置) + 时间 + 地点 + 环境背景（参考图 X）细节 + 光影 + 色调 + 其他补充细节
```

**传入参考图的格式规则（V4.0 统一）：**
- 每个关键帧必须单独列出 `**传入参考图**：` 一行
- 列出所有参考图，用逗号分隔，格式：`GX（名称）` 或 `镜头 X-X 关键帧 X`
- 顺序必须与提示词中「参考图 1」「参考图 2」的编号完全对应
- 连续镜头只参考前一帧（连续性简化原则），不重复传入原始角色图

**参考图编号对应规则（V4.0 明确）：**
- 提示词中的「参考图 1」→ 传入参考图列表中第 1 张
- 提示词中的「参考图 2」→ 传入参考图列表中第 2 张
- 以此类推

## 六、分支 2：无参考图的提示词结构（本次项目不用，但需保存）

### 6.1 提示词结构公式
```
提示词 = 统一要素 + 景别 + 镜头角度 + 构图 + (角色A，详细角色细节 + 服装细节 + 动作 + 表情) + (角色B，详细角色细节 + 服装细节 + 动作 + 表情) + 时间 + 地点 + 环境背景细节 + 光影 + 色调 + 其他补充细节 + 质量提示词
```

**说明**：统一要素为最开始确定的画面风格。

---

### 6.2 详细规则

#### 6.2.1 画面描述格式
- 由多个短语组成
- **只用逗号分隔**（除了逗号没有其他标点符号作为分隔）
- 每个短语描述一个具体的视觉元素

#### 6.2.2 用词要求
- 避免使用长句子或复杂术语
- 使用简单、常见的词语
- 示例：
  - ❌ 不要：「苦楝树絮」
  - ✅ 要用：「柳絮」
  - ❌ 不要：「错金银螭龙剑璏」
  - ✅ 要用：「精致的长剑，剑上有金银装饰」

#### 6.2.3 镜头角度与风景搭配
- 航拍、鸟瞰、高角度镜头 → 搭配「绿色的植被、地面」
- 仰拍镜头、低角度镜头 → 搭配「蓝色的天空、白色的云朵」
- 特写 → 搭配「背景虚化」

#### 6.2.4 景别
指定镜头类型：
- 特写 (ECU)
- 近景 (CU)
- 中近景 (MCU)
- 中景 (MS)
- 远景 (WS)
- 极远景 (EWS)

#### 6.2.5 色调和构图
- 色调示例：黄色复古色调、白色色调、蓝色科技感、橙色活力科技感
- 镜头角度示例：高角度镜头、低角度镜头、过肩镜头
- 风格示例：皮克斯风格、迪士尼风格、手绘风格、写实摄影风格

#### 6.2.6 主要主体描述
每个镜头中只要出现角色名称，就要在画面描述中叙述角色的特点：
- 外貌和穿着
- 在画面中的位置（全身、半身照、3/4 照片、头部及肩膀等）
- 动作（行为、表情）
- 每个镜头有且只有一次角色描述

**示例**：
```
嬴政，35岁中国秦朝男人，黑色汉服，站立，表情严肃，黑色披风，腰部以上，金色装饰品
```

#### 6.2.7 场景设置与背景元素
- 自然景观背景、户外、室内、中式园林背景、植物装饰等
- 与故事相关的重要背景元素

#### 6.2.8 其他补充细节
- 特定道具、纹理或其他关键视觉元素
- 如有特定中国朝代，应该准确提示
- 示例：红色的灯笼，百鸟朝凤刺绣花纹，秦朝，汉朝，中国古代

#### 6.2.9 质量提示词
```
大师级构图，高清，准确的光影效果，精致的画面，获奖作品，有张力的画面，极其震撼的视觉效果，最佳品质，高度创意，杰作，清晰边缘，姿态自然优美
```

## 九、后续：关键帧数量判断与工具选择（摄影指导负责）

### 9.1 关键帧数量判断规则（摄影指导优化）
- **简单运镜**（如推镜头、没有切换镜头、没有增加角色、没有复杂运镜）：只需要 **1 个关键帧**
- **复杂运镜 / 镜头切换**：可能需要 **2 个关键帧**

### 9.2 工具选择规则
- **1 个关键帧生成视频**：使用 **Seedance 工具**
- **2 个关键帧（首尾帧）生成视频**：使用 **即梦 3.0 工具**

### 9.3 职责分工
- **关键帧设计岗位**：按 2 个关键帧完成所有镜头的关键帧设计（作为基础）
- **摄影指导岗位**：后续优化和判断，决定每个镜头实际需要 1 个还是 2 个关键帧进行镜头生成
