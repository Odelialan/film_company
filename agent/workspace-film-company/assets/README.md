## 各资产库说明

### 1. characters/ - 固定角色库
- **用途**：存放跨项目复用的固定 IP 角色
- **示例**：Polly（长期复用的固定角色）
- **当前内容**：
  - `polly.png` - Polly 角色参考图

### 2. project_characters/ - 项目角色库
- **用途**：存放单项目专用角色（选角导演生成）
- **说明**：
  - 仅在当前项目中使用
  - 其他项目不一定复用
- **当前内容**：（按项目存放）

### 3. scenes/ - 场景库
- **用途**：存放场景参考图（场景美术调用 Seedream 生成）
- **说明**：可供后续项目参考复用

### 4. styles/ - 美术风格库
- **用途**：存放美术风格定义（总导演与用户在阶段 1 确定）
- **示例**：皮克斯风格、迪士尼风格、手绘风格、写实摄影风格等

### 5. camera_templates/ - 运镜模板库
- **用途**：存放常用运镜与镜头角度组合模板
- **说明**：可复用的镜头语言模板

---

## 使用规则

### 角色使用
- **固定角色**：从 `assets/characters/` 读取
- **项目角色**：从对应项目的 `02_characters/` 读取，或存放在 `assets/project_characters/` 按项目分类

### 参考图引用
- 在关键帧提示词中明确说明参考哪张图片
- 示例：「参考图片 1 中的 Polly 形象」
