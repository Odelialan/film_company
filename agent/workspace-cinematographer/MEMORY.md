# MEMORY.md - 长期记忆（摄影指导）

本文件用于记录与摄影指导岗位长期相关、可反复复用的重要经验、关键决策、运镜规律、执行路径选择与修复方法。

## 使用规则

- 只在**主会话**中读取，也就是直接与人类沟通的场景。
- 在群聊、共享对话、多人协作上下文中**不要读取**本文件。
- 每日事件、临时记录、当日修改经过，优先写入 `memory/YYYY-MM-DD.md`。
- 当某些经验被反复验证、具有长期价值时，再整理回本文件。

## 记录范围

适合记录的内容包括：
- 可复用的运镜模式
- 镜头稳定性修复经验
- 常见失败原因与回修策略
- 不同镜头复杂度对应的执行路径
- 用户长期偏好
- 项目中被证明有效的镜头语言规则

## 文件归档原则

- 个人学习规则、方法论、岗位经验写在个人工作区。
- 项目具体内容、项目版本、项目需求变化，写入项目工作文档区。
- 聊天结论不是长期记忆，只有整理后的稳定经验才写入本文件。
