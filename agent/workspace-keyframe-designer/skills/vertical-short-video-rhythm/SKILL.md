# 竖屏短视频节奏优化

## Pattern

`pipeline`

## Purpose

当上游内容已经确定为竖构图输出时，对现有镜头、分镜、关键帧计划或提示词进行竖构图节奏优化，确保目标画幅、安全区、镜头密度、钩子设计、爽点密度与 AI 生成适配规则一致。

## When To Use

- 用户明确要求输出 `9:16`、`3:4` 或 `2:3` 竖构图视频、竖屏短剧、短视频短剧、短剧切条或 reels 风格内容。
- 上游关键帧、分镜、镜头计划中已经出现 `9:16`、`3:4`、`2:3`、`竖屏`、`竖构图`、`手机端观看`、`字幕安全区` 等明确信号。
- 需要把已有镜头方案改成更适合 Seedance、可灵、即梦等工具生成的竖屏节奏版本。

## Do Not Use

- 横屏 `16:9`、方形 `1:1`、电影宽画幅、电视长剧标准镜头设计任务。
- 用户仅要求画面美术、服化道、光影风格，而没有节奏优化目标的任务。

## Required Inputs

- 原始镜头方案、分镜、关键帧计划或待优化提示词。
- 目标画幅：`9:16` / `3:4` / `2:3`。若未给出，但已明确是竖构图任务，则标记 `【待确认：目标画幅】`。
- 目标时长：`1min` / `3min` / `10min`。若未给出，则标记 `【待确认】`，并按最接近档位暂代。
- 内容品类：`sweet` / `god_of_war` / `suspense` / `comedy` / `other`。若未给出，则从内容主导情绪推断并标记 `【待确认】`。
- AI 工具：`seedance` / `keling` / `jimeng` / `none`。若未给出，默认 `none`。

## Required Files

- `prompt-template.md`
- `checklist.md`

## Instructions

1. **先确认是否为竖构图任务**：只有当输出目标明确为 `9:16`、`3:4` 或 `2:3` 任一竖构图时才继续；若不是竖构图任务，停止使用本 skill。
2. **先确认目标画幅**：输出中必须继承目标画幅，不能把 `3:4` 或 `2:3` 强行改写成 `9:16`；若画幅缺失，仅可标记 `【待确认：目标画幅】`。
3. **读取上游内容**：先提取现有镜头中的时长、冲突点、爽点、对白密度、景别分布、运镜强度与结尾钩子状态，不改写剧情事实。
4. **完成三项分类**：
   - 时长分类：`1min` / `3min` / `10min`
   - 品类分类：`sweet` / `god_of_war` / `suspense` / `comedy` / `other`
   - 工具分类：`seedance` / `keling` / `jimeng` / `none`
5. **按模板顺序组装规则**：必须依次加载 `prompt-template.md` 中的四层内容，并按下面顺序拼装：
   - 通用基础模板
   - 对应品类模板
   - 对应时长后缀
   - 对应 AI 工具后缀（若有）
6. **执行节奏优化**：把拼装后的规则应用到现有镜头方案中，重点只调整以下维度：
   - 目标画幅与信息安全区
   - 单镜头时长与镜头总数
   - 特写占比与景别分布
   - 钩子、冲突点、爽点、注意力唤醒点
   - 转场与镜头运动强度
7. **产出优化结果**：输出时必须明确说明：
   - 识别到的目标画幅、时长档位、品类、AI 工具
   - 采用了哪些模板片段
   - 优化后的节奏规则或提示词后缀
   - 如果需要，也可同步给出镜头层面的改写建议
8. **执行验收**：必须逐项对照 `checklist.md` 检查结果。
9. **不合格则回退重做**：只要有任一强制必过项未通过，就不得交付最终结果，必须重新优化后再检查。

## Output

输出应包含以下四部分：

1. `竖构图识别结果`
2. `分类结果（目标画幅 / 时长 / 品类 / AI 工具）`
3. `最终采用的节奏规则`
4. `验收结果`

若上游任务需要提示词后缀，可直接输出一段可拼接到上游提示词末尾的竖屏节奏描述。

## Constraints

- 不得把本 skill 用于非竖构图任务。
- 不得改写剧情关键事实、人物关系或事件结果；只允许优化镜头节奏与呈现方式。
- 不得同时拼接多个品类模板；只能选择一个主导品类模板。
- 不得把目标画幅从 `3:4`、`2:3` 自动改写为 `9:16`。
- 不得跳过验收清单。
- 若信息缺失，只补最小必要假设，并明确标注 `【待确认】`。
