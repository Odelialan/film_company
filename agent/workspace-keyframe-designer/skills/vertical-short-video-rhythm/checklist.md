# 竖屏短视频节奏验收清单

## 使用规则

- 强制必过项只要有一项不满足，即判定为 `不合格`，必须重新优化。
- 若任务目标画幅为 `9:16`、`3:4` 或 `2:3`，验收时必须严格匹配该目标比例，不能私自替换。
- 完播率优化项建议全部达标；未达标时应说明风险。
- 品类适配项只检查当前选中的主导品类。
- AI 生成适配项只在需要对接对应生成工具时检查。

## 强制必过项

| 检查项 | 合格标准 | 结果 |
| --- | --- | --- |
| 画幅适配 | 严格匹配目标竖构图比例（9:16、3:4 或 2:3），无黑边、无变形 | ▢ |
| 信息安全区 | 所有核心信息（人脸、台词、重要道具）在画面上2/3区域，避开底部字幕或 UI 遮挡 | ▢ |
| 前3秒钩子 | 前3秒有明确强冲突、反差或结果前置钩子，能够留住用户 | ▢ |
| 单镜头时长 | 平均单镜头时长≤2秒，普通叙事镜头≤2秒，冲突或爽点镜头≤1.5秒，情感特写最长不超过4秒 | ▢ |
| 特写占比 | 近景和特写镜头占比≥80%，中景≤15%，大远景≤5%（特殊需求除外） | ▢ |
| 动态要求 | 80%以上镜头带轻微运动（推、拉、摇、跟），完全静止镜头≤20% | ▢ |
| 转场要求 | 硬切转场占比≥90%，软转场（淡化、闪黑等）≤10% | ▢ |
| 结尾钩子 | 最后5秒有明确下集钩子，停在冲突最高点 | ▢ |

## 完播率优化项

| 检查项 | 合格标准 | 结果 |
| --- | --- | --- |
| 注意力唤醒点 | 每15秒有一个注意力唤醒点（镜头震动、音效、字幕弹窗等） | ▢ |
| 冲突密度 | 1分钟剧至少2个冲突点，3分钟剧至少5个冲突点，10分钟剧每2分钟至少1个大冲突点 | ▢ |
| 爽点密度 | 1分钟剧至少1个爽点，3分钟剧至少3个爽点，10分钟剧每3分钟至少1个大爽点 | ▢ |
| 无冗余镜头 | 没有无意义空镜头或明显拖节奏的长镜头 | ▢ |

## 品类适配项

| 品类 | 检查项 | 合格标准 | 结果 |
| --- | --- | --- | --- |
| 所有品类 | 节奏匹配 | 节奏符合所选主导品类的优化规则 | ▢ |
| `sweet` | 特写占比 | 特写占比≥90%，情侣同框优先肩以上景别 | ▢ |
| `god_of_war` | 冲突节奏 | 冲突点镜头切换速度提升20%，爽点配合镜头拉近动效 | ▢ |
| `suspense` | 节奏变化 | 前半段舒缓营造氛围，后半段揭秘时节奏提升30% | ▢ |
| `comedy` | 包袱设计 | 包袱前有1秒固定镜头铺垫，抖包袱时用特写放大笑点 | ▢ |

## AI 生成适配项

| 检查项 | 合格标准 | 结果 |
| --- | --- | --- |
| 提示词适配 | 节奏描述符合对应 AI 工具（Seedance、可灵、即梦）的语法要求 | ▢ |
| 生成稳定性 | 避免过于复杂的镜头运动导致生成画面崩坏 | ▢ |
| 一致性 | 镜头运动与景别切换逻辑连贯，不出现跳脱画面 | ▢ |

## 判定规则

- 强制必过项全部通过：才允许交付最终结果。
- 总体达标但建议项有缺口：可以交付，但必须显式标注风险。
- 评分参考：
  - 90分以上：S级爆款节奏，完播率预计≥45%
  - 80-89分：A级优质节奏，完播率预计≥35%
  - 70-79分：B级合格节奏，完播率预计≥25%
  - 70分以下：不合格，重新优化
