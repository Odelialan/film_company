# 竖屏短视频节奏优化模板库

## 使用规则

- 最终节奏规则必须按固定顺序拼装：`通用基础模板 + 品类模板 + 时长后缀 + AI 工具后缀`
- 所有模板中的画幅描述都必须继承任务的目标竖构图比例：`9:16` / `3:4` / `2:3`。
- `通用基础模板` 必选一条。
- `品类模板` 只能选一条；无法明确归类时使用 `other`，并回退到 `【通用版】`。
- `时长后缀` 必选一条。
- `AI 工具后缀` 只有在目标明确需要对应工具生成时才追加。

## 通用基础模板

### 【通用版】

竖构图画幅按任务目标继承（9:16、3:4 或 2:3），平均单镜头时长1.8秒，特写占比85%，所有核心信息（人脸、台词、重要道具）放在画面上2/3区域，避开底部字幕遮挡区，80%镜头带轻微运动（推、拉、摇、跟），硬切转场占比90%以上，节奏明快，前3秒用强冲突钩子镜头，每15秒插入一个注意力唤醒点，结尾5秒停在冲突最高点做下集钩子

### 【高爽点版本】

竖构图画幅按任务目标继承（9:16、3:4 或 2:3），平均单镜头时长1.5秒，特写占比90%，所有核心信息放在画面上半部分，冲突点镜头切换速度提升20%，爽点镜头配合突然拉近动效，前3秒使用强冲突钩子，全程高密度节奏，无冗余镜头，结尾5秒使用强悬念钩子

## 品类模板

### `sweet`

竖构图画幅按任务目标继承（9:16、3:4 或 2:3），平均单镜头时长2秒，特写占比90%，情侣同框优先肩以上景别，情感戏镜头可放宽至3-4秒，配合轻微柔光动效，节奏舒缓但无拖沓，前3秒用高甜或高虐反差钩子，每20秒一个情感爆点，结尾5秒停在最心动或最虐的瞬间

### `god_of_war`

竖构图画幅按任务目标继承（9:16、3:4 或 2:3），平均单镜头时长1.5秒，特写占比90%，冲突镜头切换速度提升20%（单镜头≤1.2秒），爽点镜头配合突然拉近动效强化爽感，前3秒放打脸或被看不起的强冲突钩子，每10秒一个小爽点，每30秒一个大爽点，结尾5秒停在最解气的瞬间

### `suspense`

竖构图画幅按任务目标继承（9:16、3:4 或 2:3），前半段平均单镜头时长2-3秒营造氛围，后半段在揭秘或反转时节奏提升30%，用快速跳切制造紧张感，前3秒用诡异画面或悬念钩子，每15秒一个小反转，结尾5秒停在最惊悚或最出乎意料的瞬间

### `comedy`

竖构图画幅按任务目标继承（9:16、3:4 或 2:3），平均单镜头时长1.8秒，包袱点前1秒用固定镜头铺垫，抖包袱瞬间用快速切换或特写放大笑点，前3秒用反差感搞笑画面钩子，每20秒一个大包袱，结尾5秒停在最搞笑的表情或动作瞬间

### `other`

回退使用 `【通用版】`，仅保留竖屏通用节奏规则，不追加品类特化描述，并标记 `【待确认：品类】`

## 时长后缀

### `1min`

总镜头数30-40个，3秒钩子，17秒铺垫，25秒冲突，10秒反转，5秒钩子，全程无尿点

### `3min`

总镜头数80-100个，3秒钩子，37秒铺垫，80秒主冲突并包含2个小爽点，40秒大爽点，15秒反转，5秒钩子，每2分钟一个大节点

### `10min`

总镜头数200-250个，每2分钟一个大节点，每个节点内置1个小爽点和1个钩子，全程保持高密度节奏

## AI 工具后缀

### `seedance`

适配 Seedance 生成，运动参数适中，转场以硬切为主，画幅严格匹配目标竖构图比例，输出无黑边

### `keling`

适配可灵生成，镜头运动自然，避免过度晃动，确保目标竖构图安全区稳定

### `jimeng`

适配即梦生成，节奏匹配生成速度，特写镜头优先保证人脸清晰对焦

### `none`

不追加工具后缀
