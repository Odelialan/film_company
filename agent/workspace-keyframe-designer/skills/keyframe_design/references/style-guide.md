# 关键帧设计 · 文风与版式规范

本文件约束 `keyframe-design` Skill 的书面形式。真实规则源以 `/home/honeycake/project/film-company/agent/workspace-film-company/KEYFRAME_DESIGN_STANDARD.md` 为准；本文件只做执行摘要，便于在生成时快速对齐。

## 语言

- 正文说明、节奏阐释、对接说明：**简体中文**。
- 镜头类型、模块名可与参考 YAML 中的英文键并列出现，便于与分镜工具或检索一致（例：`Shot_Reverse_Shot` / 正反打）。

## 首要原则

- 输出目录目标固定为：`07_keyframes/KEYFRAME_PLAN.md` 与 `07_keyframes/SEEDREAM_KEYFRAMES.md`。
- 不再输出自定义单篇「镜头序列报告」。
- 生成前必须先判断：**有参考图** / **无参考图**。
- `KEYFRAME_DESIGN_STANDARD.md` 与项目模板冲突时，以前者为准；若模板结构与标准都存在，则在不破坏模板骨架的前提下执行标准。

## 时长与编号

- 写法：`数字 + s`（秒）或 `数字 + min`；极短镜头可用 `0.2s` 等形式。
- 蒙太奇快切可单列一行「节拍组」并在「节奏/剪辑备注」中标明节拍同步方式。
- 关键帧编号建议使用 `场次-镜头-关键帧`，如 `1-2-1`。
- 全局参考图编号固定使用 `G1 / G2 / G3 / G4 ...`，只用于索引，不直接替代提示词中的 `参考图 X`。

## 文件结构

- `KEYFRAME_PLAN.md`：写计划、依赖、全局参考图、交付清单、进度与下游说明。
- `SEEDREAM_KEYFRAMES.md`：写镜头描述、对白、镜头类别、运镜提示词、关键帧提示词、传入参考图、格式检查。
- 两个文件头部的「固定参考图（全局编号，仅用于索引）」必须一致。

## 表格与列

- 默认章节顺序以项目模板为准；不得删除模板中的必填块。
- `KEYFRAME_PLAN.md` 中的交付清单写摘要，不写完整提示词。
- `SEEDREAM_KEYFRAMES.md` 中每个镜头必须先有 `镜头描述`、`对白`、`镜头类别`，再有 `运镜提示词`，然后才是关键帧条目。

## 提示词书写

- 有参考图项目：
  - 使用标准中的分支 1 结构公式。
  - 每个关键帧必须单独写一条完整提示词。
  - 每个关键帧必须单独写 `**传入参考图**：...`。
  - 提示词里的 `参考图 1/2/3` 必须与传入参考图顺序一一对应。
- 无参考图项目：
  - 使用标准中的分支 2 结构公式。
  - 用多个短语组成，只用逗号分隔。
  - 每个角色在单个关键帧中只描述一次。

## 符号与标注

- **【待确认】**：用户未提供且影响关键帧设计的信息（是否有参考图、固定角色路径、场景参考图路径、项目风格基准、时长上限等）。
- **Jump Scare / 反转 / 匹配剪辑**：可以写在镜头描述或运镜提示词中，但最终关键帧提示词仍应保持静态画面导向。
- **轴线 / 越轴**：若涉及对话正反打，在镜头描述或运镜提示词中说明，不在关键帧静态描述里展开运动过程。
- **对白**：继承自分镜阶段；无对白必须明确写 `无`，不要留空。
- **镜头类别**：继承自分镜阶段，推荐直接沿用分镜导演的分类命名；若上游未给出，则标 `【待确认】`。

## 静态与运动边界

- `镜头描述`：保留导演镜头意图与叙事目的。
- `对白`：只承接分镜阶段已有内容，不在关键帧阶段自行改写台词。
- `镜头类别`：作为镜头用途标签保留，便于后续摄影指导和审片。
- `运镜提示词`：单独写推、拉、摇、移、跟、升降等运动方式。
- `关键帧`：只写静态时刻画面，不写连续动作过程。

## 频控与克制（摘要）

- Jump Scare：单支短片内不宜过多；具体频控以 `references/suspense-thriller.md` 为准。
- 反转：须具备铺垫段与揭示段，避免无铺垫硬转。

## 与参考文档的关系

- 关键帧格式、分支规则、参考图编号规则、双同步要求，以 `KEYFRAME_DESIGN_STANDARD.md` 为唯一总标准。
- 场景语言、节奏语法、镜头参考，则从各 `references/*` 文档中抽取。
- `assets/report-template.md` 只说明如何映射到 `07_keyframes/` 双文件，不替代项目模板本身。

## 下游边界

- 本 Skill **不**输出最终调色值、精确焦距毫米数、分灯表；可写 Seedream 所需画面关键词与运镜说明。
- 竖屏具体裁切与节奏比例调整由「竖屏短剧节奏优化」类 Skill 处理；此处仅在计划文件里标注是否需要。
- 最终还应满足标准中的「双同步」要求：写入 `07_keyframes/`，并将关键帧提示词同步给用户。
