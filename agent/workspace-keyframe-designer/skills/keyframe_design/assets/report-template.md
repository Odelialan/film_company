> 本文件不是最终交付文档本身，而是 `keyframe-design` Skill 的输出映射说明。最终产出必须拆分为项目目录下的两个文件：

> - `/home/honeycake/project/film-company/agent/workspace-film-company/projects/_PROJECT_TEMPLATE/07_keyframes/SEEDREAM_KEYFRAMES.md`

> 生成时优先复用上述模板原有章节标题与顺序；本文件只说明每部分应该填什么。

## 文件一：`KEYFRAME_PLAN.md`

### 必填块

1. 文件头元信息
   - 状态
   - 版本号
   - 更新时间
   - 维护人
   - 项目名

2. `⚠️ 强制风格统一要求`
   - 若项目已有固定风格基准，必须写明与固定参考图统一
   - 风格关键词必须与项目实际风格一致

3. `关键帧设计原则`
   - 必须保留 1 个或 2 个关键帧判断逻辑
   - 必须强调「每个关键帧只描述静态画面，不描述运动」
   - 必须保留参考图清单要求

4. `上游依赖文件`
   - 至少列出分镜主文件、角色设定、场景细化、固定参考图
   - 路径未知时写 `【待确认】`

5. `固定参考图（全局编号，仅用于索引）`
   - 使用 `G1 / G2 / G3 / G4 ...` 表
   - 与 `SEEDREAM_KEYFRAMES.md` 头部保持一致

6. `关键帧交付清单`
   - 按场次列出镜头编号和关键帧编号
   - 只写计划级摘要，不写完整提示词

7. `进度跟踪`
   - 保留五个阶段：上游读取、计划制定、关键帧设计、关键帧生成、双同步交付

8. `下游使用说明`
   - 至少保留摄影指导、视频生成、后期统一三项

## 文件二：`SEEDREAM_KEYFRAMES.md`

### 必填块

1. 文件头元信息
   - 状态
   - 版本号
   - 更新时间
   - 维护人
   - 项目名

2. `⚠️ 规则说明`
   - 必须解释「参考图 X」与「传入参考图」的顺序映射
   - 必须保留连续性简化原则

3. `固定参考图（全局编号，仅用于索引）`
   - 与 `KEYFRAME_PLAN.md` 头部一致

4. `场次 / 镜头 / 关键帧` 主体结构
   - 每个镜头必须包含：
     - `镜头描述`
     - `对白`
     - `镜头类别`
     - `运镜提示词`
     - `关键帧 1`
     - `关键帧 2`（仅在需要 2 个关键帧时）
   - 每个关键帧必须包含：
     - `提示词`
     - `传入参考图`

5. `格式检查`
   - 七条核对项必须保留
   - 关键帧统计必须填写

6. 末尾 `固定参考图（全局编号，末尾重复索引备用）`
   - 与头部索引保持一致

---

## 有参考图项目的填充规则

- 提示词必须遵循 `KEYFRAME_DESIGN_STANDARD.md` 中的分支 1 结构公式。
- 每个关键帧都要单独列出 `传入参考图`，并保证提示词中的 `参考图 1/2/3...` 与传入顺序严格一致。
- 连续镜头优先参考前一帧，避免重复传入原始角色图。
- 镜头描述保留导演原意；运镜信息单独写在 `运镜提示词`，不要混入关键帧静态描述。
- `对白` 与 `镜头类别` 继承自分镜阶段，不在关键帧阶段擅自重写；无对白时明确写 `无`。

## 无参考图项目的填充规则

- 提示词遵循标准中的分支 2 公式。
- 使用统一要素 + 景别 + 镜头角度 + 构图 + 角色描述 + 环境 + 光影 + 色调 + 质量提示词。
- 角色描述每个关键帧中对每个角色只出现一次。
- 使用逗号分隔短语，不写冗长解释句。

## 输出顺序

1. 先生成 `KEYFRAME_PLAN.md`
2. 再生成 `SEEDREAM_KEYFRAMES.md`
3. 最后自检：
   - 全局编号表是否两文件一致
   - 关键帧数量是否与镜头复杂度匹配
   - `参考图 X` 是否与 `传入参考图` 顺序一致
   - 是否满足双同步要求
