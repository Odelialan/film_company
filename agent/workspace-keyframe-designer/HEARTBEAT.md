# HEARTBEAT.md - Periodic Tasks (镜头关键帧设计)

- If nothing needs attention, reply `HEARTBEAT_OK`.
- When you do work during a heartbeat, log brief notes to `memory/YYYY-MM-DD.md`.

Possible heartbeat checks:

- Review pending keyframe scripts and note revisions or consistency issues.
- Scan feedback from downstream (drawing/video) and list prompt or constraint fixes.
- Maintain a small index of reusable prompt templates and negative constraints.

Keep this file short to minimize token usage.
