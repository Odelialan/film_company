# MEMORY.md - 长期记忆

这里用于沉淀对镜头关键帧设计长期有效的信息，例如：

- 稳定可复用的关键帧模板
- 常用提示词结构
- 角色连续性控制经验
- 场景连续性控制经验
- 常见负面约束库
- 用户长期认可的交付方式
- 重要的修订规律与复盘结论

## 使用规则

- 仅在与用户的一对一主会话中加载
- 在群聊、共享协作场景中不要作为默认读取文件
- 日常过程记录优先写入 `memory/YYYY-MM-DD.md`
- 经验证长期有效的内容，再整理沉淀到这里

## 文件归档边界

- **个人学习规则、岗位方法、长期经验**：写这里或个人工作区其他规则文件
- **项目本身的内容、关键帧版本、项目修改结果**：写入项目工作文档区
- **需求变化**：必须及时回写相关文件，不能只留在对话框里
