## Skill 调用规则

### 调用总原则

- 先判断任务是否命中关键帧正式交付；命中私有 skill 时优先调用私有 skill。
- 私有 skill 负责标准化交付，普通讨论、单点判断、短答不要强行套 skill。
- 多段镜头、批量关键帧、复杂版本整理时，优先调用 `planning-with-files`。
- 用户纠正关键帧结构、提示词口径、镜头拆分标准后，调用 `self-improving` 复盘。
- 涉及长期提示词偏好、固定格式、常见错误与稳定流程时，调用 `elite-longterm-memory` 记录。

### 私有 skill 工作流

- `keyframe-design`：当需要把分镜或镜头序列转成 `07_keyframes/KEYFRAME_PLAN.md` 与 `07_keyframes/SEEDREAM_KEYFRAMES.md` 正式交付物时调用。
- `vertical-short-video-rhythm`：只要目标画幅是 `9:16`、`3:4` 或 `2:3`，就必须联动调用；它负责竖构图节奏、安全区、镜头密度和验收。
- 两者同时命中时，先按 `keyframe-design` 进入主流程，并在识别到竖构图后强制加载 `vertical-short-video-rhythm` 作为联动子流程。

### 本岗位可用的全局 skill

- `planning-with-files`：长链路关键帧项目、跨场次批量生成、版本收敛。
- `seedream4.x`：当用户明确要求直接试生成参考关键帧、验证提示词可用性或补充视觉草图时使用。

### 不要误用

- 横屏或非竖构图任务，不要调用 `vertical-short-video-rhythm`。
- 没有正式 `07_keyframes/` 交付目标时，不要滥用 `keyframe-design`。

## 即梦 Dreamina 工具接入

- 本岗位可以使用 `dreamina-cli` skill 调用 `/home/honeycake/.local/bin/dreamina`。
- 当用户明确要求生成关键帧图片、验证关键帧提示词、把关键帧转视频时，读取 `skills/dreamina-cli/SKILL.md`。
- 图片结果必须进入当前项目 `07_keyframes/KEYFRAMES/`。
- 视频结果必须进入当前项目 `09_assets/processed/`。
- 未登录、余额不足、合规授权缺失或任务失败时，不写占位文件，直接返回 Dreamina CLI 的真实错误。
