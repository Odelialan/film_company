## 阶段 1：需求定义与视觉顶层设计（总导演全责，必须在所有执行前完成）

### 负责人
- **唯一责任人：总导演**

### 输入
- 用户的原始想法/参考/素材/要求

### 必须完成的交付物（全部写入项目工作文档区）
| 文件 | 位置 | 核心内容 | 验收标准 |
|---|---|---|---|
| `USER.md` | 总导演工作区 | 需求版本记录、版本变更历史、当前需求全貌 | 8 大要素齐全（IP/平台/时长/风格/分辨率/内容类型/重点侧重/硬约束） |
| `PROJECT_BRIEF.md` | `项目目录/00_admin/` | 项目简报，一句话总结、核心目标、硬约束 | 任何岗位读此文件就能知道「做什么、给谁看、什么不能做」 |
| `VISUAL_STYLE_GUIDE.md` | `项目目录/05_visual/` | 视觉风格总定义、造型语言、材质方向、与角色配合规则 | 明确「真实度/夸张度/细节重点」，明确「不能做什么」 |
| `COLOR_SCRIPT.md` | `项目目录/05_visual/` | 主色/辅助色分工、色彩情绪曲线、各场景/段落色彩倾向 | 角色色与背景色层级清晰，无大面积竞争色 |
| `REFERENCE_BOARD.md` | `项目目录/05_visual/` | 视觉参考图、参考说明、「像什么/不像什么」边界 | 参考图明确，且有文字说明「学什么、不学什么」 |

### 必须在阶段 1 就明确的 8 大要素（写入 `USER.md`）
1. **是否使用已有 IP / 角色 / 模板**（如有，明确识别锚点与不可变动项）
2. **目标平台**（抖音/快手/视频号/小红书/B站/其他，明确观看场景）
3. **时长**（总时长范围 + 关键节奏点，如：前 3 秒钩子）
4. **美术风格**（写实/二次元/扁平插画/赛博朋克/写意国风/手书等 + 参考）
5. **分辨率比例**（如：9:16、16:9、1:1 等）
6. **内容类型**（小说推文/剧情短片/漫剧/广告片/口播混剪/其他）
7. **重点侧重**（剧情/视觉/人物/带货转化/信息传达清晰度）
8. **硬约束**（时长强约束/敏感词/审核红线/品牌/IP 限制/角色是否固定）

### 阶段 1 完成的自我检查清单
- [ ] 我能用一句话把项目说清楚
- [ ] 8 大要素已全部明确，没有「待定」项
- [ ] 视觉风格顶层定义已完成， downstream 岗位知道「往什么方向做」
- [ ] 所有交付物已写入项目工作文档区，不仅停留在对话框
- [ ] 已更新 `USER.md` 版本号与变更记录

## 阶段 4：分镜设计

### 负责人
- 分镜导演

### 上游输入
- 剧本、视觉风格、角色设定

### 交付物
- `STORYBOARD_MASTER.md`（主分镜文件）
- 镜头清单（可选：`SHOTLIST.csv`）
- 节奏笔记（可选：`RHYTHM_NOTES.md`）

### 强制技术规则（必须 100% 遵守）
1. **一个镜头只承担一个主变化**
2. **一个镜头最多对应两个关键帧**
3. **景别统一使用中文**（远景、中景、中近景、近景、特写，不要用 MCU 等英文缩写）
4. **使用准确方位描述**（如「画面左侧」，不要说「画面一侧」）
5. **关键帧只描述静态画面，不描述运动**（关键帧是定格的，只说「谁在什么位置，什么姿态」）
6. **关键帧一句话说完，用逗号分隔，不分段**

### 验收标准
- 所有强制技术规则 100% 符合
- 分镜完整覆盖剧本所有内容
- 节奏符合目标时长
- 分镜摘要已同步到对话（双同步：写文件 + 对话告知）

## 阶段 5：场景美术落地

### 负责人
- 场景美术

### 上游输入
- 总导演的视觉风格顶层定义（`05_visual/` 下的文件）
- 分镜导演的完成分镜（`STORYBOARD_MASTER.md`）

### 交付物
- `SCENE_BIBLE.md`（场景圣经，含逐镜头场景细化与穿帮检查）
- `LIGHTING_GUIDE.md`（灯光指南）
- `LOCATION_OR_SET_NOTES.md`（场地/置景说明）

### 核心任务
1. **逐镜头确定关键帧内容**：基于分镜，把每个关键帧的场景细节补全
2. **穿帮检查**：保证空间连续性
   - 例：上一个镜头小恐龙在滑梯右边，角色未移动则下一个镜头仍需保持在右边
   - 例：同一座滑梯的颜色、朝向、结构在所有镜头中保持一致
3. **场景细节补足**：让每个镜头的场景都具体、可落地

### 验收标准
- 所有镜头的空间连续性一致，无穿帮
- 场景细节完整，下游岗位（关键帧设计、摄影指导）知道「每个镜头具体长什么样」
- 与总导演的视觉风格顶层定义保持统一
- 场景细化内容已写入项目工作文档区

## 通用规则与存档要求

### 全员必须遵守的存档规则（强制）
1. **个人内容 vs 项目内容**
   - 个人学习规则、工作方法、长期经验：写入**个人工作区**
   - 项目相关内容、版本变更、阶段产出：统一写入**公司项目工作文档区**
   - 禁止：项目内容只留在对话框，不写入文件

2. **交付结果双同步（强制，所有重要产出都必须执行）**
   - 重要产出（剧本、分镜、角色、视觉定稿、场景细化、关键帧、摄影方案等）：
     1. **第一步**：写入项目工作文档区
     2. **第二步**：把**完整的、可直接审阅的核心内容**同步贴入对话框告知用户（不是简单一句「已完成」，而是要贴出具体内容）
   - **各岗位对话框同步内容示例**：
     - 分镜导演：完整分镜（场次、剧本内容、镜头描述、关键帧、对白）
     - 场景美术：逐镜头场景细化与穿帮检查
     - 关键帧设计：每个关键帧的具体优化/设计内容
     - 摄影指导：完整摄影语言、运镜方案、光影方案
   - 禁止：只改文件不说话；也禁止只说话不改文件；也禁止只贴一句「已完成」而不贴具体内容

3. **项目文档区保持稳定**
   - 优先在现有既定文件里更新内容
   - 不要随便新增文件
   - 如真的需要新增，先跟总导演确认

### 项目目录结构标准
```
项目目录/
├── 00_admin/           # 项目管理：简报、状态、职责、变更记录
├── 01_story/           # 故事：故事大纲、世界观
├── 02_characters/      # 角色：角色设定、选角结果
├── 03_script/          # 剧本：完整剧本、对白稿
├── 04_storyboard/      # 分镜：主分镜、镜头清单、节奏笔记
├── 05_visual/          # 视觉风格（总导演负责）：风格指南、色彩脚本、参考板
├── 06_scene/           # 场景（场景美术负责）：场景圣经、灯光指南、场地说明
├── 07_keyframes/       # 关键帧：关键帧设计稿
├── 08_cinematography/  # 摄影：运镜方案、摄影指导
├── 09_assets/          # 资产：参考图、素材
├── 10_edit/            # 剪辑：剪辑方案、时间线
├── 11_audio/           # 音频：配乐、配音、音效
├── 12_delivery/        # 交付：成片、版本
└── 13_review/          # 审阅：审阅意见、修改记录
```
