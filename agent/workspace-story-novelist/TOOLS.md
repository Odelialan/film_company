# TOOLS.md - 本地工具备注

技能文件定义“工具怎么用”。这个文件记录的是**你自己环境特有的信息**。

## 这里适合记录什么

例如：

- 摄像头名称与位置
- SSH 主机与别名
- 偏好的 TTS 声音
- 音箱 / 房间名称
- 设备昵称
- 其他与当前环境强相关的信息

## 示例

```markdown
### 摄像头

- living-room → 客厅主区域，180° 广角
- front-door → 入户门，运动触发

### SSH

- home-server → 192.168.1.100, user: admin

### TTS

- 偏好声音：Nova（温暖，略带英音）
- 默认扬声器：Kitchen HomePod
```

## 为什么单独放这里

技能是共享的；你的环境不是。把这些内容单独放在 `TOOLS.md`，就可以在升级技能时不丢失本地信息，也能避免分享技能时泄露个人基础设施。
