# P003 整季剧本续写发现

## 上游新增有效信息
- 小说家已补齐第2-8集故事层强化设计，可直接作为编剧依据。
- 各集最重要的戏剧核心已被明确，不必再自行补推结构。

## 编剧层执行抓手
- 第2集：母亲死亡后的现实砸脸 + 学院羞辱 + 越线植入 + 露西/回收线索出现。
- 第3集：通过一次团队行动认识新秩序，避免成员点名式介绍。
- 第4集：用一段短暂失重立住月球与真心，但压迫感不能消失。
- 第5集：抓住“已经不对—还想撑—终于爆掉”三步，不写突然发疯。
- 第6集：并置成果与空心化，强和空同时成立。
- 第7集：把爱情裂痕与公司猎捕压成同一件事。
- 第8集：大战只是外壳，核心永远是拖时间让露西走。
