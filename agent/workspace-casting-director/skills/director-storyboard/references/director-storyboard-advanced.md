# 导演分镜进阶规则

本文件是 `SKILL.md` 的高级补充模块，不单独使用。

## 何时读取

当出现以下任一情况时读取本文件：

- 用户明确要求高质量精修
- 角色塑造、魅力塑造、反派压迫感是重点
- 对话需要更细的停顿、潜台词和正反打变化
- 动作段落需要更强的冲击力和动作链
- 需要高级转场、视觉修辞、记忆闪回、情绪留白

## 使用原则

- 先服从 `SKILL.md` 的主流程
- 本文件只负责提高镜头质量，不改变主模板结构
- 如与主文件表述冲突，以本文件的精修规则为准
- 精修的目标是“更准确”，不是“更花哨”

## Module A：角色深度塑造

### A1. 角色魅力塑造

- 魅力要通过动态细节建立，一个瞬间的微动作通常强于长时间静止特写
- 每个主要角色至少设计一个“标志性姿态镜头”，来源于角色气质，而不是外貌标签
- 脆弱时刻优先抓取身体失守的细节，例如颤抖指尖、失焦眼神、无意识自我安慰动作
- 坚定时刻优先用逆光、侧光和体态轮廓表达力量感
- 情绪外溢时用特写捕捉情绪的物理轨迹，例如眼泪、指节发白、嘴角抽搐

### A2. 风格化魅力强化

- 仅在项目确实需要风格化角色卖点时启用
- 可以设计身体线条、衣物材质、发丝动态等镜头，但必须服务角色塑造
- 不允许把角色镜头降级成纯视觉消费

### A3. 反派与群像

- 反派登场优先伴随环境失衡，例如光线变暗、声音消失、构图倾斜
- 为反派设计重复性病态微动作，形成辨识度和不适感
- 反派的压迫感通常来自“不动时的威胁”而非一直夸张运动
- 群像中设置一个焦点配角，用其反应引导观众情绪
- 人群反应要拆成多层反应链，避免所有角色同时做同一动作

## Module B：高级镜头语言

### B1. 景别与构图

- 平拍是默认中性视角；低角度用于权力和压迫，高角度用于渺小和无力
- 角色内心不安可使用荷兰角，但必须有明确心理动机
- 前景构图可以增强层次、窥视感和空间压迫
- 过肩镜头中的肩膀远近和虚实应服务关系表达
- 物件特写等于宣布该物件重要，不可滥用
- 运动方向必须预留空间，避免画面挤压错误

### B2. 运镜

- 推镜速度要与角色情绪增长速度同步
- 拉镜用于揭示角色与环境、群体或命运的关系
- 摇镜的起幅和落幅都必须成立，不能只顾中间运动
- 长镜头结尾需要信息增量，否则会变成拖沓
- 角色调度通常优先于炫技式运镜
- 手持和晃动镜头必须有情绪或主观视角动机

### B3. 视觉修辞

- 镜像、倒影、剪影可用于表达双面性、隔阂或自我冲突
- 空镜头也必须保留风、光影、烟尘、水波等动态元素
- 场景中的物件要尽量承担叙事功能

## Module C：精密动作拆解

### C1. 动作链增强

- “起势”镜头必须让观众读懂角色意图
- “落点”镜头必须给出物理反馈，例如碎裂、震动、灰尘、失衡
- 受伤后的第一反应应匹配角色性格，而不是统一套公式
- 死亡或失去力量的镜头，优先让一个承载生命力的视觉符号消失或变化

### C2. 常见动作模板

- 拔剑：剑鞘特写 → 眼神特写 → 手握剑柄特写 → 拔出
- 开门：根据心态判断是推、撞、潜入、踹开还是迟疑试探
- 追逐：核心不是快，而是障碍变化、距离变化和路径变化
- 打斗：至少安排一个慢动作或极强停顿镜头展示力量顶点或致命一击

## Module D：对话拆镜精修

### D1. 台词呼吸感

- 按逗号停顿、语气转折、词语信息量和情绪层次拆镜
- 逗号是插入听者微表情镜头的机会
- 停顿是插入环境细节或信息物件镜头的机会
- 台词说完后不要立刻切走，留出半拍回味空间

### D2. 正反打变化

- 正反打应持续变化角度、景别和焦距，避免机械重复
- 激烈争吵优先考虑同框过渡、焦点转换和角色调度
- 潜台词优先通过“角色 A 说话，镜头给角色 B 反应”来表达
- 说谎、退缩、隐瞒时可以利用遮挡嘴部、避开视线等细节

### D3. 对话视觉化

- 一句完整台词默认至少考虑三个关注点：说话的人、听话的人、沉默的空气
- 角色说台词时应同步执行平行任务，避免站桩背词
- 关系变化要在构图距离、站位和视线中体现出来

## Module E：高阶衔接技法

### E1. 转场

- 匹配转场每场戏最多使用一次，避免失去力量
- 记忆闪回必须在色调、画幅、质感或节奏上与主时空明显区分
- 角色思绪混乱时，可用快速碎片化剪辑表达信息断裂
- 一场戏的最后一个镜头决定这场戏留给观众的最终情绪

### E2. 节奏

- 当节奏需要放缓时，优先给一个真正成立的长镜头
- 当节奏需要加快时，优先让多个短镜头各自承担清楚的信息推进
- 成本最高或视觉最重的镜头要放在情绪峰值，而不是平均分散

## Module F：终极戒律

- 一个镜头如果不能同时服务至少两个维度，通常应被删掉或合并
- 先做减法，再做加法
- 不要爱上单个镜头，要爱上整场戏的情绪逻辑
- 分镜脚本必须减少执行歧义，而不是制造解释空间
- 只有在完全理解规则时，才允许有意识地打破规则

## 精修自检补充项

在主文件自检基础上，再确认以下问题：

1. 每个主要角色是否有基于其核心气质的标志性姿态镜头？
2. 反派登场是否伴随环境失衡或心理压迫？
3. 群像反应是否被拆成多层反应链？
4. 正反打是否有角度、景别和焦距变化？
5. 动作高潮是否有明确落点和物理反馈？
6. 匹配转场是否被克制使用？
7. 最重的镜头资源是否放在了情绪峰值？
8. 是否遗漏了潜台词镜头或听者反应镜头？
