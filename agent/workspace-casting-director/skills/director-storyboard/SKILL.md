# 导演分镜生成器

## Purpose

必须把剧本类输入（全剧、单场、梗概或已有分镜草稿）转成可执行的逐镜头分镜文本。主交付物必须遵守 `STORYBOARD_MASTER.md` 的字段顺序与固定规则。景别/视角/声音/衔接等仅可作为内部推演草稿；面向用户的最终块仍必须完全符合模板。

## 何时使用

当用户提出以下任一需求时必须加载本 skill：

- 分镜 / storyboard
- 拆镜头 / shot breakdown
- 导演板 / shotlist
- 场次镜头细化
- 需要镜头分类以便下游对话 / 动作 / 情感 / 悬疑 / 蒙太奇分支
- 写入或更新 `04_storyboard/STORYBOARD_MASTER.md`

## Pattern

- 声明为 `generator`：以模板与固定结构生成成品。
- 主目标不是审查、多轮问答门禁、或封装工具；优先级规则下也不应把本 skill 归类为 `reviewer` / `inversion` / `pipeline` / `tool-wrapper` 为主。

## 输入门禁（最小）

若缺信息会导致范围错误，则只问必要项（禁止长问卷）：

1. 范围：整集 / 单场 / 若干镜头 【待确认】
2. 题材倾向：对话 / 动作 / 情感 / 悬疑惊悚 / 混合 【待确认】
3. 模式：新建 / 补全 / 重写 / 局部修改 【待确认】
4. 落盘路径：禁止猜测项目名称；须向用户确认项目名或完整路径 【待确认】

## Instructions

必须按顺序执行：

1. **确认范围** — 判定整集、单场或镜头区间；判定是改已有 `STORYBOARD_MASTER.md` 还是纯对话内输出。
2. **落盘前读模板** — 若任务为写入 `.../04_storyboard/` 下文件，必须先读取 `metadata.primary-template` 或目标项目内同名 `STORYBOARD_MASTER.md`，再沿用其标题层级与字段键名。
3. **节拍拆解** — 每段用一句话说明戏剧目的；以情绪节拍为最小单位；标出转折、信息点、氛围变化。
4. **先分类再写镜头** — 每个镜头必须有且仅有一个主分类，取自：`对话场景镜头` | `动作戏镜头` | `情感戏镜头` | `悬疑惊悚镜头` | `蒙太奇与转场镜头`。允许 `主分类 + 次标签`，但次标签不得替代主分类。
5. **前置建构（按需）** — 仅在叙事需要时补建立镜头；首镜定调；避免无动机的平庸全景开场。
6. **逐镜头撰写** — 每镜一个主变化；每镜最多两个关键帧；关键帧为静态单句、逗号分隔、景别中文、方位用 左/右/上/下/中 等明确描述。
7. **覆盖与节奏** — 动作链：起势→过程→落点→反应。对白链默认：说话者起势→听者反应→说话者高潮→结束后反应。听者反应通常优先于台词本身的信息量。
8. **衔接** — 每次切换须有动机；情绪或空间跳转优先复合衔接逻辑。衔接标签词表：`动作顺接 | 情绪因果 | 视线引导 | 台词驱动 | 音效桥接 | 同框过渡 | 焦点转换 | 角色调度 | 匹配转场 | J-Cut | L-Cut | 逻辑因果 | 对比反差 | 节奏硬切`。
9. **进阶精修** — 若用户要求精修，或张力/动作/反派/群像/转场为戏核，必须读取并应用 `references/director-storyboard-advanced.md`，且不得改变外层模板字段名。
10. **发送前自检** — 必须完成本文件「自检」清单。

## Output

### 每镜必填块（Markdown）

必须按以下键名与顺序输出：

```markdown
#### 镜头 N
- 镜头描述：
- 关键帧 1：
- 关键帧 2：
- 对白：
- 镜头分类：
```

规则：

- 无对白时对白写 `无`。
- `镜头分类` 不得为空。
- 关键帧不得描述连续运动；每行一句；逗号分隔；关键帧内不允许再分段。

### 分批输出

若单次输出过长：

- 每批最多 30–40 个镜头。
- 批次末尾必须标注 `【续】`；全局镜头编号必须连续。

### 体量参考（非强制）

- 约 1–2 分钟成片常见约 60–120 个镜头，按节奏调整。
- 约 500 字剧本约对应约 1 分半体量；禁止为凑数增镜或偷懒减镜。

## Constraints

禁止：

- 用「同上」「略」「余略」等省略镜头正文。
- 输出缺少 `镜头分类` 的分镜。
- 在用户要求模板合规时擅自改字段名或合并必填键。
- 未经用户明确要求时在仓库内额外新建说明类文档。
- 未确认时编造项目路径或项目名。

必须：

- 优先保证画面可读性：尽量在静音下仍能读懂主要情绪与推进（具体比例不因本 skill 强制数值化，除非用户明确要求）。
- 为声音与剪辑留空间：画面不要塞满到无法承载音效与对白锚点。

## 自检（发送前）

1. 每镜是否至少服务叙事、角色、情绪中的两项？
2. 是否存在无意识的同景别连镜？
3. 跳转处衔接动机是否清楚？
4. 对白段落是否按需要完成拆镜？
5. 动作段落是否在需要处完成动作链？
6. 每镜 `镜头分类` 是否便于下游分支 skill？
7. 若应加载进阶文件，是否已读取并应用？

## Guiding principles

- 剧本是地图，分镜是挖掘，不是复述。
- 价值在增补镜头的合理性，不在镜头数量本身。
- 分镜是制作契约：减少执行歧义，避免解释空间。
