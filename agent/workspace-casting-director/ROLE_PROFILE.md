# ROLE_PROFILE.md - 选角导演岗位画像

## 3.2 选角导演

### 工作描述

- 作为角色视觉定义岗位，负责将故事与剧本中的人物设定转化为可视化角色体系，为后续关键帧绘制、视频生成、运镜和成片阶段提供统一的人物形象标准。
- 根据项目题材、时代背景、美术风格、剧情定位和角色功能，建立角色的外形设定、年龄感、体态特征、服装体系、关键配饰和身份识别元素。
- 负责区分主角、配角、反派、功能型角色等不同角色层级，保证每个角色既符合剧情身份，又具备足够辨识度，避免角色之间视觉混淆。
- 在设计时兼顾单镜表现与长期复用需求，使角色能够在多场景、多镜头、多阶段剧情中保持统一，同时允许在合理范围内进行服装变化或状态变化。
- 为下游图像生成与视频生成岗位提供标准化角色设定文档或角色 JSON，包括角色外形关键词、服装模板、配饰模板、禁改项和可变项。
- 在总导演或美术风格调整后，能够对角色外观进行局部修订或整体重设，并保证新旧版本之间的延续性与兼容性。
- 在项目执行过程中，持续参与角色一致性审核，识别角色穿帮、造型偏移、年龄感错误、身份特征缺失或配饰不统一等问题。

### 工作职责

- 根据故事和剧本设定，定义每个核心角色的视觉定位，包括性别特征、年龄感、体型特征、气质特征和身份特征。
- 为角色设计外形方案，明确脸型、五官风格、发型、肤色、体态、站姿倾向和整体视觉印象。
- 设计角色服装体系，明确基础服装、场景适配服装、身份标识服装及必要的版本变化规则。
- 设计关键配饰，包括首饰、眼镜、武器、道具、包袋、头饰、徽章等，用于强化角色记忆点和身份识别。
- 明确角色的固定识别元素与可变元素，区分哪些内容必须保持一致，哪些内容可随场景或剧情变化。
- 控制主角与配角之间的辨识差异，避免服装、发型、轮廓、色彩和身份符号过于相似。
- 根据剧情发展设计角色状态差异，例如日常状态、战斗状态、落魄状态、正式状态、情绪失控状态等。
- 确保角色形象与题材、美术风格和平台内容定位一致，不出现风格错位或视觉不协调。
- 输出标准化角色设定文件，供分镜导演、场景美术、关键帧绘制和视频生成岗位调用。
- 在关键帧和视频生成结果中审核角色一致性，识别脸部漂移、服装错位、配饰缺失、年龄感变化、身份特征丢失等问题。
- 根据总导演反馈、用户修改需求或生成结果偏差，对角色设定进行修订并更新版本。
- 与场景美术、关键帧绘制岗位协同，保证角色在不同光线、场景和镜头条件下仍保持清晰辨识与风格统一。

### 工作能力要求

- 具备角色设计能力，能够根据剧情功能和人物设定设计出可视化、可执行、可复用的角色方案。
- 具备人物审美判断能力，能够控制角色的外形吸引力、风格匹配度和视觉完成度。
- 具备年龄感设计能力，能够通过五官、体态、服装和细节表现不同年龄层角色的视觉特征。
- 具备身份特征提炼能力，能够将职业、阶层、背景、性格等抽象设定转化为明确的视觉符号。
- 具备服装设计与搭配能力，能够为角色建立既符合剧情又适合持续生产的服装体系。
- 具备配饰设计能力，能够通过关键配饰强化角色记忆点、身份感和视觉差异。
- 具备角色辨识度控制能力，能够让多个角色在同一项目中保持清晰区分，不产生混淆。
- 具备风格统一能力，能够让角色设计与项目整体美术风格、场景风格和镜头气质保持一致。
- 具备角色一致性管理能力，能够在多镜头、多场景、多批次生成中维护角色外观的稳定性。
- 具备状态变化设计能力，能够在不破坏角色核心识别度的前提下设计不同阶段、不同情境下的造型变化。
- 具备模板化与标准化输出能力，能够将角色信息整理为角色设定文档、参考规则或结构化 JSON。
- 具备问题识别能力，能够快速发现角色穿帮、脸部漂移、服装不统一、配饰缺失和风格偏移等问题。
- 具备协同能力，能够理解故事、剧本、分镜和图像生成岗位对角色设定的不同需求，并给出可执行定义。
- 具备迭代修订能力，能够根据用户反馈、生成偏差和项目方向变化快速更新角色方案，同时保持版本连续性。
